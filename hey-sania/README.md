# Hey Sania

The connector and the discipline for using it, in one plugin.

- `skills/hey-sania/SKILL.md` — how to read a curated corpus well: search wide before
  narrowing, cite what was found, say plainly what the sources do not cover, and ask the
  editors to look into a gap rather than answering thinly from the nearest one.
- `.mcp.json` — the server at `https://heysania.ai/api/mcp`. It runs its own
  OAuth, so Claude sends you there to sign in and approve at first use and is given a
  token of its own. Nothing to paste.

The skill is generated from the copy the app serves, where a test holds it to the
server's actual tools. Do not edit it here; edit it there and republish.

Installation, what the sources cover, and how to take a connection back:
[heysania.ai/connect](https://heysania.ai/connect).
